🔑 Anthropic API Key

Need an API key? Get one from console.anthropic.com

Your key is stored locally in your browser and never sent anywhere except to Anthropic's API.

To hardcode your API key directly in the HTML file:

  1. Open pdf-to-obsidian.html in a text editor
  2. Find the line that says: const HARDCODED_API_KEY = null;
  3. Replace null with your API key in quotes: 
    const HARDCODED_API_KEY = 'sk-ant-api03-YOUR-KEY-HERE';
  4. Save the file

⚠️ Security Warning: Only hardcode your key if this file is for personal use only. Don't share or commit a file with your API key to GitHub!
